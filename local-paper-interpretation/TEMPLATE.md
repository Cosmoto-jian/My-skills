## 0. 标题与文件名

- 文件名 = 文章标题：`{来源}｜{机构}｜{一句话核心结论}.md`
  （例：`arXiv｜南洋理工大学｜蛋白语言模型里藏着一个"线性适应度子空间"，定向进化效率大幅提升.md`）
- 正文内不再写 `# 标题` 行（文件名即标题，发布工具取文件名）
- md 顶部先放公众号摘要 HTML 注释，再接论文信息卡

## 1. 论文信息卡（浅灰底卡片，字段名加粗）

- 原文标题（英文）
- 期刊：arXiv / 会议 / 期刊名
- 发表时间
- 第一作者（机构）
- 全部作者名单

（注：作者单位列表不再单独成节，信息已包含在"第一作者（机构）"字段中）

## 3. 摘要框（顶部高亮引用框：浅蓝灰底 + 深青色左侧竖线 + 圆角）

两段式，同一块内上下排列，中间无分割线（紧凑）：

- 第一段：**研究目的**——对象 / 瓶颈 / 收益三要素（skill 硬规则：开头先写目的）
- 第二段：**核心结论**——一句话可验证的结论

## 4. 正文分节（01–07 数字编号）

分节标题样式：深青色数字方块（01）+ 浅色底横幅 + 青色加粗标题文字。
节内无更细子标题；每节 2–5 个自然段；每节 1–3 个关键结论句用**深青色加粗**高亮。

### 01 引言（3 段）

- 领域瓶颈是什么（旧世界为什么不够）
- 现有两类方法的局限（各有什么做不到）
- 提出本文要回答的核心问题

### 02 核心假说/发现（5 段）

- 关键定义（新概念首次出现时：定义 + 英译中/怎么理解）
- 假说内容（分层次讲清）
- 支撑假说的关键实验证据（带数字，定位到论文小节）
- 维度/规模分析（如适用）
- 补充验证（迁移性、泛化性等）

### 03 方法（5 段）

- 总体流程（一句话 + 流程图占位 `![图N](...)`）
- 关键步骤拆解（每步解决哪个瓶颈，与 §01/§02 对应）
- 与基线方法的本质区别
- 核心思想一句话总结（青色加粗高亮）

### 04 主要结果（5 段）

- 评估设置说明（数据集/测定数量）
- 主结果：本文方法 vs 基线（带统计显著性）
- 计算成本/效率对比
- 扩展评估（如有）
- 一句话结论（青色加粗高亮）

### 05 消融与分析（3 段）

- 关键组件消融（对照组分别证明什么）
- 超参/策略消融
- 组件间互补关系

### 06 附加分析（3 段，如论文有）

- 生物学/物理意义关联（如适用）
- 跨场景迁移结果
- 对领域认知的增量

### 07 原文结论与局限性（2 段）

- 原文结论（一句话）
- 局限性（诚实列出：数据依赖、假设前提、未覆盖场景）
- 可复现性（代码/数据是否开源）

## 5. 参考文献（灰色小字）

- 英文引用 × N（作者. 年份. 期刊/arXiv:编号）

## 6. 结尾

- 文末写「原文链接：<完整URL>」（裸 URL 直接写出，不用 markdown 链接语法；公众号内跳转不了，读者靠复制打开）
- 无额外互动引导话术

## 7. 公众号摘要（每次定稿后必写）

- 120 字以内，基于正文内容写一段摘要
- 放在 md 顶部 HTML 注释中（`<!-- 公众号摘要（N字）：... -->`），不影响正文渲染，发布时复制填入摘要栏

## 图片规范

- 正文配图：论文原图（流程图、曲线图、热图），宽幅居中
- 图注格式：`图N｜图题`（黑体加粗，置于图下方）
- 每张图配一句话解读：这张图证明了什么
- 图注编号与论文原文 Fig. 编号对应，补充图用 S1、S2……

## 写作硬规则（来自 skill，逐条执行）

1. 开头先写研究目的，再写核心结论（§3 摘要框）
2. 旧瓶颈 → 关键动作必须有因果链，不能跳步（§01→§02→§03）
3. 每个数字必须能定位到论文小节；只读摘要不算深度解读
4. 英文术语首次出现附"英译中 / 怎么理解"
5. 核心公式教科书式展开：回答什么问题 → 符号含义 → 直觉 → 回扣关键动作
6. 一个概念一段，不堆术语
7. 证据边界声明：哪些来自论文、哪些是推断
8. 局限性诚实写，不吹捧

## 排版硬规则（2026-10-07 用户反馈沉淀）

1. 每段顶格写，行首不空格
2. 图片按 Fig 编号顺序出现（图1→图2→图3→图4），不许图2后面冒出图1；
   总览/流程图（Fig 1）放摘要框后、01 之前
3. 论文信息卡、摘要框：保留内容，去掉标题行（"论文信息卡""摘要"字样不出现）
4. 去提示词痕迹：不写"先给关键定义""（诚实版）"这类暴露指令的字眼，内容照写
5. 图注不用加粗：`图N｜图题`纯文本，不包 `**`
6. 正文不出现 § 节号（如 §5.3），数字归属用自然语言带过或省略
7. 参考文献节标题写"主要参考文献"，只放 5 篇最主要的
8. 含下划线的公式/符号（如 s_wt、N_init）用反引号包裹，防止 markdown 斜体误解析
9. 行内不出现连续双空格（删节号等操作后要压缩空格）

## 自检清单（成文后逐项核对）

- [ ] 论文信息卡字段齐全（标题/期刊/时间/第一作者/全部作者）？
- [ ] 作者单位卡齐全？
- [ ] 摘要框两段式（目的 + 结论）？
- [ ] 01–07 分节齐全，节内 2–5 段？
- [ ] 每节有 1–3 个青色加粗关键句？
- [ ] 每张图有 `图N｜图题` 图注 + 一句话解读？
- [ ] 每个数字可定位到论文小节？
- [ ] 消融三问分开回答（组件/策略/互补）？

- [ ] 全文一条逻辑链：目的→瓶颈→假说→方法→证据→边界？

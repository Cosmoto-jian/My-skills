# 论文解读写作

> 本 skill 的结构、排版、流程以同目录下的 `TEMPLATE.md` 为准（skill 与模板对齐，以模板为准）。
> 模板体例：生元 BioView 公众号风格，文件名即标题，输出 Markdown，落盘后由发布工具转排版。

## 写前先查原文

- 打开论文原文再动笔。按出版商分流抓全文：
  - Nature 系（Nat Commun / Nat Methods 等，开放获取）：用浏览器只读任务逐字提取全文、全部图注、数据/代码声明、参考文献；图用 `media.springernature.com` 官方直链，把 URL 中的 `/lw685/` 换成 `/full/` 拿高清 PNG。
  - ACS 付费墙：走浏览器机构订阅读全文，图用 CDN 签名直链立刻下载（有时效）。
  - arXiv / PMC：直接读 HTML 全文，图从 HTML figures 目录下载。
  - ScienceDirect：浏览器任务 + 机构访问，图用 els-cdn 直链。
- 付费墙走不通就直说，绝不编造正文内容。用户声称有权限也要先让浏览器确认页面出现订阅/机构标识再承诺。
- 在 PubMed 核验发表信息（期刊、卷期、日期、DOI），编号看着像旧年份也要核。
- 动笔前通读本 skill 一遍，把排版硬规则和去提示词痕迹清单过一遍再写；同时读一遍经验库（见配套 skill `paper-lesson-loop`，`../paper-lesson-loop/scripts/read_lessons.py`）。

## 按七节结构成文（与 TEMPLATE.md 一致）

- 全文七节：**01 引言 / 02 核心发现 / 03 方法 / 04 主要结果 / 05 消融与分析 / 06 附加分析 / 07 原文结论与局限性**；摘要框前置。
- 每节结论先行：先给本节结论再展开，不写"我先查了…然后…"这类过程叙述。
- 文件名直接用文章标题（`{来源}｜{机构}｜{一句话核心}.md`），正文里不再写 `# 标题` 行。
- 定稿后写一段 120 字内的公众号摘要，精简、有趣、有钩子、不说教，放在 md 顶部 HTML 注释里。
- 文末用裸网址写原文链接（`原文链接：https://…`），公众号里 markdown 链接跳不过去。

## 排版硬规则

- 段落顶格写，行首不加空格，全文不出现连续双空格。
- 图片按 Fig 编号顺序出现（图1→图2→图3→图4），总览图紧跟摘要框之后。
- 信息卡和摘要框保留内容但去掉标题行；作者单位不单独成节，并入信息卡。
- 图注不加粗；正文不出现 § 节号；"参考文献"改叫"主要参考文献"，只列 5 篇。
- 含下划线的公式或符号用反引号包裹（如 `s_wt`），防止被渲染成斜体。
- 图注格式：`图N｜图题` + 一句话解读，解读句说明"这张图证明了什么"。
- 主要参考文献选篇规则：奠基性 1 篇 + 直接前作/基线 2 篇 + 方法 1 篇 + 应用 1 篇。

## 去提示词痕迹

- 术语解释写成自然行文：术语加中文加一句解释，不要套"（英文，英译中：… / 怎么理解：…）"这种机械括号。
- "一句话总结"是内容要求，不是让你把"一句话："三个字写出来；全文扫一遍，删掉所有"一句话："标签式前缀。
- 指令动词不许出现在正文："先把…说清楚""要诚实…""先给关键定义""（诚实版）"这类词一个都不留。
- 全文扫一遍中英混杂，把裸英文词换成中文（如 "handful" 换成"少数几种"）。
- 口语生动和 sloppy 一线之隔，压住"证据很硬""真是从头造的"这类词，改成"证据相当扎实""确为从头设计"。

## 忠实度核对

- **数字核对表**：动笔前从原文摘出所有关键数字列成表（样本量、PSM 数、召回率、KD、分辨率、pH 等），注明出处小节/图号；成文后逐项打勾，凡是"凭印象写"的数字一律回原文重查。run-level 与全局质控后这类易混数字必须分开列。
- 每个数字逐项回原文核对，一个都不能凭印象写。
- 正文和图注数字打架时以正文为准；论文自身数字前后矛盾时（如摘要百分比与图中柱值对不上），按图写并在 07 节诚实指出。
- 交稿前跑一遍模板自检：七节齐全、摘要框前置、图序正确、排版硬规则逐项过。

## 交稿前终审

- 定稿后、上传前，把"公众号摘要 + 每节加粗关键句"先发用户过目，确认方向无误再上传发布。用户确认后再归位。

## 交付

- 上传时必须保留 md 引用的子目录结构（`figs/figN.png` 按相对路径原样上传，禁止拍扁到根目录）；上传后核对目录树与 md 引用一致。
- 写完后从理解、忠实原文献、读者易读性、文字写作表达四方面总结经验，用配套 skill `paper-lesson-loop` 的 `write_lesson.py` 写回经验库。

## 配套

- `TEMPLATE.md`：七节结构与排版模板（本 skill 的执行依据）。
- `../paper-lesson-loop/`：经验库读写脚本（动笔前读、写完后写），保持迭代闭环。

## 参考网站

- [arXiv](https://arxiv.org/)：全文与配图。优先读 HTML 版而非 PDF，图从 HTML 的 figures 目录下载，每个数字回原文核对。
- [PubMed](https://pubmed.ncbi.nlm.nih.gov/)：发表元数据。核验期刊、卷期、日期、DOI，DOI 看着像旧年份也要核。
- [PMC](https://pmc.ncbi.nlm.nih.gov/)：开放获取全文。直接读 HTML；有 Graphical Abstract 的话可作总览图。
